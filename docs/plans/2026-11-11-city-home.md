# 主城首页改版实施计划

**目标：** 主城与底部功能栏组成一屏可操作的游戏画面，移除首页阵容和堆叠回报，保留既有玩法入口。

**实现：** `CityView.vue` 负责场景及面板调度；新增 `CityDock.vue` 和 `CityNavIcon.vue`，分别负责底栏入口和本地像素图标。`App.vue` 仅在主城模式使用满屏布局，并为提示气泡避让底栏。服务端、存档与请求流程不变。

**技术：** 复用 Vue 3、TypeScript、CSS 和内联 SVG，无新增依赖。

## 1. 场景与信息层级

- 修改 `frontend/src/views/CityView.vue`：场景填充剩余视口，建筑保留点击与真实状态，天色控件浮在右上。
- 左下提供可点击的当前目标，右下保留收取收益；手机地图在独立区域横向浏览。
- 删除首页 `PartyStrip`、七入口文本导航和大段回报；阵容继续在出征准备中显示。
- 验证：常用桌面尺寸和 390px 手机下首页不整体溢出，七座建筑入口可达，目标跳转正确。

## 2. 底栏与出征

- 新增 `frontend/src/components/CityDock.vue`、`CityNavIcon.vue`：宗门、弟子、值守、炼丹、炼器、问道六入口，本地绘制像素图标。
- 突出问道入口，真实状态切换为问道、继续出征或待结算，未开放码头仅留地图入口。
- 验证：底栏和建筑打开相同面板，出征中返回宗门不改变进度，弹窗焦点和只读限制保持有效。

## 3. 结果与主框架

- 修改 `frontend/src/App.vue` 的主城布局与气泡避让，保留原有气泡任务的所有改动。
- 修改 `frontend/src/views/SectPanel.vue`：宗门总览保留挂机明细，并补充最近出征回报。
- 更新 `README.md` 和 `DESIGN.md` 的主城交互说明，不改道具任务的文档段落。
- 验证：收益可收取并显示气泡，详细回报可在总览查看；主城与出征界面往返正常。

## 4. 验证与交付

- 使用隔离测试数据库启动本地后端，专用浏览器页与真实 API 验证交互，不读取或改写用户存档。
- 实际检查桌面、手机、短屏、昼夜、弹窗、等待和错误状态，留截图。
- 运行后端全部测试、工具全部测试、配置与 RNG 校验、契约生成、前端全部测试与类型构建。
- 检查最终 diff，仅交付当前任务的改动，保护已有工作区内容；历史图标及气泡任务的完整验收另行处理。
