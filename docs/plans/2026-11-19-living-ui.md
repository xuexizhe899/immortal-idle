# 游戏页面鲜活度优化

目标：在现有修仙放置游戏中强化人物、经营和历练的识别度，让真实状态与操作反馈更容易被感知。保留已完成的分栏、详情弹窗、左右切换、地图局部滚动和顶部战斗决策入口。

## 视觉与交互方向

- 雾纸 `#f6f1df`、松墨 `#213f36`、青玉 `#326c55`、淡竹 `#dfe8cf`、旧木 `#8c6844`、鎏金 `#b38a46`。延续细像素素材、木版刻线和青玉嵌边，避免玻璃面板、统一圆角卡片和大面积装饰渐变。
- 宋体用于宗门与人物题名，雅黑用于操作和说明；数值使用等宽数字排列，不加载外部字体。
- 主城以场景为主体，资源和目标保持短小；弹窗围绕当前事务组织内容，不把全部详情同时展开。
- 人物用现有立绘和实际身份、岗位、伤势、装备形成差异；经营页呈现真实设施、配方和岗位；地图与历练页强调当前进度、节点状态和下一步。
- 动效主要回应资源快照变更、按钮按下、面板打开和选中状态。减少动态效果偏好下关闭位移动画，不以闪烁、持续飘粒子或假进度制造热闹。

```text
主城：[宗门题签] [已入账资源] [当前存档状态]
      [                  原有主城场景                 ]
      [可行动的修行目标]                 [同步挂机收益]
      [宗门 / 弟子 / 值守 / 炼丹 / 炼器 / 山河 / 问道]

事务：[标题题签 / 相关状态]                    [关闭]
      [原有栏目导航]
      [当前任务与真实状态，次要详情按需打开]
```

方向自查：将表现重点放在宗门、人物、工坊和山河的区别上，不增加与玩法无关的宣传标题，不统一包成同一种卡片，不为了装饰增加页面高度。配色沿用用户已经明确的美术方向。

## 范围与完成证据

| 范围 | 预期结果 | 验证方式 |
|---|---|---|
| 公共底座、主城与导航 | 层次统一，资源变化可感知，真实存档状态明确，主要入口仍在一屏内 | 类型检查、相关主城/交互测试、代码审查 |
| 公共弹窗与反馈 | 弹窗层次、焦点与关闭保留；普通/错误/处理中可区分 | 现有弹窗与反馈相关回归，减少动态效果代码检查 |
| 弟子、培养、换装与道法 | 人物身份突出，个人成长与装备清楚，详情左右切换保留 | 弟子与装备相关回归 |
| 主殿、设施、收益、值守 | 实际岗位与产出更清楚，累计收益语义不退化 | 经营、挂机记录与导航相关回归 |
| 炼丹、炼器、库存、材料与存档 | 工坊和物品具有识别度，操作和风险确认保留 | 炼制、装备、材料、存档相关回归 |
| 地图、征讨、整备和出征 | 节点、队伍和真实进程更易识别，主要行动前置 | 地图、整备、路线与宗门战相关回归 |
| 桌面与390px、键盘、长内容、加载错误、减少动态效果 | 不因美化破坏原有可用性 | 源码与自动回归；实际显示由用户人工验收 |

本轮不修改后端、存档、接口、玩法数值或依赖，不调用付费生图，不碰真实存档，不部署。按仓库约定不做浏览器渲染或视觉验收；代码和构建通过不等同于人工体验验收。完成记录与本轮实际命令另记在审查文档中。
