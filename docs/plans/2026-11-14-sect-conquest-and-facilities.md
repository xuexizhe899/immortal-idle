# 宗门征讨与设施经营实施计划

**目标：** 将远行改为固定外宗的擂台征讨与战后驻守，补齐三级设施、生产专长、装备丹药成长及便捷调度。

**架构：** 服务端继续独占资源与战斗计算，整档 JSON 和 revision CAS 保存。新玩法复用战斗计算与战报播放，不复用问道塔选路和道法流程。新增字段提供默认值，已有器具、专武、服药记录按一级衔接，旧进行中的塔式远征保留结束路径。

**技术栈：** FastAPI / Pydantic / SQLite / Vue 3 / TypeScript / Pinia，沿用既有依赖。

## 已确认规则

- 本宗主殿就是宗门等级，初始一级，上限三级；其他四设施不得高于主殿。一级生成三座外宗，每升一级增加三座，攻克后保留。
- 出发3–6名弟子，每场选三名进行3v3擂台，最多三轮。血量延续，倒下者本局不能再上场；不足三人结束。胜利存活3/2/1人扣守备50/30/15，失败不扣；守备100，提前归零直接进入3v1宗主战。
- 出发扣两点行动力；宗主胜利才发一次攻克奖励。失败与撤退不保留敌方战役血量，不替换宗门身份。交战后失败或撤退，只给实际参战成员一层伤势；未上场替补不受罚。关闭页面可继续。
- 外宗一个驻守点容纳0–3人，各自产出相加，匹配生产专长增益更高，无凑满奖励。生产按既有12小时补算与时间事件切段执行。
- 值守/驻守弟子可直接入队，完成出发校验后原子离岗；结算释放后自动回原岗位，岗位满保留现有人选并提示。
- 炼丹支持数量、最大可炼和品级；一键队伍疗伤优先库存（包含旧疗伤丹），只补炼缺额，材料不足优先重伤者，同伤势按队列，一次提交。
- 每名弟子配置一项生产专长。新增基础材料灵木、青石、赤铜、妖兽皮；新增专材攻伐器胚、护持器胚、破境灵材，服务多个配方。
- 炼器设施解锁器具/专武等级上限，逐件消耗材料升级。器具只增加该器具新旧效果差额。炼丹设施解锁品级，属性丹强化名额满后高阶替换最低阶，只补差额。
- 问道塔按设施和前阶通关解锁更高阶，单局仍20层；演武升级提高上岗弟子的产出贡献。藏经阁改名弟子堂。

## 数值首版基线

- 设施与物品最多三级，器具/属性丹/专武效果倍率1 / 1.5 / 2；具体消耗在配置和预览中统一展示。
- 四种新增基础材料每小时0.5；无驻守不产专材。外宗每位驻守者每小时提供基础材料 `0.5 × 宗门等级` 与专材 `0.15 × 宗门等级`，专长匹配对应产物时翻倍。
- 演武等级提高弟子贡献至1 / 1.25 / 1.5倍；本宗材料专长提供对应基础时产的额外100%乘该倍率，不靠品质统一覆盖专长优势。
- 新档和旧档不会因为读取重复领取材料。升级费用不得要求只能由该升级之后才能获得的材料。
