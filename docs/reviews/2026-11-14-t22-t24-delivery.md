# T22–T24 与远行码头交付检查

2026-11-14（北京时间）。本轮按持续目标接手已有修改，完成 T22 路线、T23 复盘、T24 公共视觉基准和远行码头代码。未部署；视觉与体验由用户人工验收。

## 实现结果

- **T22**：候选保存真实有序编成、面板战力和胜利奖励；同类去重，数量不足诚实展示单路线。首领仍仅第 20 层。旧局沿用快照层段和原 RNG 顺序。新增“直接看结果”演出选项，不替玩家选路或道法。
- **远行码头**：12 段、2 点行动力、末段首领、材料偏重的既有奖励，复用同一状态机；API 限定 tower/expedition，独立远行记录，入侵未开放。主城入口、准备、出征、结算形成闭环。
- **T23**：结算原子保存最近一局末战事实摘要，列明倒下者、存活敌人、我方治疗/护盾和三条最高伤害记录，提供培养或疗伤/专武入口。缺记录不伪造统计，导航不自动消费。
- **T24**：有限公共样式调整，保留弹窗和气泡脚本；提供宗门总览与丹药/长柄武器两种独立 HTML 样板，不增加正式演示入口或外部依赖。

额外修正了本轮范围内的问题：候选气血取整与实际战力统一；无 variants 的 v2 模式仍保存真实编成；实时模式删除后仍按出发快照结算；护盾不混计敌方；远行正确使用“段”，复盘不把战前气血当作生命上限，不以局内残血替代当前伤势。

旧局强制使用固定 encounters 的建议经修改前提交核对后撤销：T20/T21 原本就支持快照 variants，保留此行为才是兼容。对应回归覆盖第 1、11、20 层。
