# T21 词条与构筑设计

2026-11-13。状态：设计待确认，未改代码。

## 0. 现状核对（读代码与配置得出，非沿用任务卡描述）

### 0.1 词条如何生效

`run_engine.with_affixes()` 把已选词条的 `effects`（全部 `add_pct`）按 atk / def / hp / spd 汇总，乘到 `party_snapshot.combatants` 的副本上。战斗结束后不改写快照，因此每次战斗重算一次，不会累积。

结论：**词条只能改四个属性，进不了 `battle.py` 的 `bonuses` / `actions` 通道**。这是"连击、破甲、护盾"这类名字无法落地的根因。

### 0.2 已有能力（可复用）

| 能力 | 位置 | 现状 |
|---|---|---|
| 条件判定 | `battle.condition_matches` | `always` / `shielded` / `first_round` / `target_weakened` 四选一 |
| 数值修正 | `battle.total_bonus` + `apply_effect` | `damage` / `healing` / `shielding` 三个键，按加法叠加 |
| 护盾 | `Unit.shield` / `apply_effect` | 同源取较大值、不同源共存、总量不超上限 |
| 动作 | `BattleAction` | damage / heal / shield / buff，目标含 enemy_first / enemy_lowest / all_enemies / ally_lowest |
| 羁绊 | `battle` 联动段 | 可改系数、加目标、加时长、追加动作，带 condition |

结论：**三个条件、三个修正键、护盾机制都是现成的**，词条可以直接复用，不需要新造战斗框架。

## 1. 设计目标与非目标

### 目标

1. 让同一套队伍在不同敌情、剩余气血和已选道法下产生**不同但都合理**的选择。
2. 词条效果必须能在战报中看到来源，不能只有面板数字。
3. 三种打法（收割、护盾、持久）都能用现有 16 人技能与 4 组战斗羁绊组出来。
4. 数量不扩：仍是 20 条 / 3 组。

### 非目标

- 不新增词条数量、不新增第四组。
- 不新增节点、不改 20 层结构与选路节奏（T22）。
- 不改战斗框架、不加新的动作类型、不加脚本或逐角色硬编码。
- 不做复盘面板、不改主城与全站视觉（T23 / T24）。

## 2. 效果类型与执行顺序

### 2.1 四类效果

| 类型 | 作用 | 落地位置 | 是否新增 |
|---|---|---|---|
| 属性（attr） | atk / def / hp / spd | `with_affixes` 现有逻辑 | 复用 |
| 常驻修正（flat） | damage / healing / shielding / taken_damage | `BattleUnit.bonuses` | 复用 + 增 1 键 |
| 条件修正（cond） | 满足条件时追加上述修正 | `BattleUnit.conditional_bonuses` | **新增字段** |
| 无 | — | — | — |

不引入 `actions`。原因：词条若给每个主动技能追加动作，会让治疗、护盾类技能也附带攻击效果，语义失控；且 4 条效果上限容易被词条挤爆。三种打法用修正与条件已经足够。

### 2.2 执行顺序（固定，不随选择顺序变化）

```
出发：基础属性 → 等级/境界成长 → 伤势 → 宗门与个人永久加成 → 专武
局内：属性词条 → 常驻修正 → 条件修正（按当前行动目标判定）
行动：主动/被动修正 → 羁绊修正 → 最终伤害/治疗/护盾
```

条件**只看本次行动开始时的状态**（沿用 `condition_matches` 的现有语义），不追溯本次刚施加的降防或护盾。

### 2.3 上限（防止单键堆满）

| 修正键 | 常驻上限 | 条件上限（多条同时满足时） |
|---|---|---|
| damage | +20% | +35% |
| healing | +30% | +20% |
| shielding | +30% | +20% |
| taken_damage（减伤） | −20% | −15% |

超出部分截断，不报错。属性词条不设全局上限，但每条自身固定。

## 3. 三种打法

### 3.1 破甲收割（锋锐 4 条为核心）

| 环节 | 内容 |
|---|---|
| 参与弟子 | 关羽、赵云、杨戬、后羿（高攻主动） |
| 核心道法 | `shi_ru_po_zhu` 势如破竹（对残血 +15% 伤害）、`lie_jia` 裂甲（对降防 +12%） |
| 配合道法 | `yi_gu_zuo_qi` 一鼓作气（首轮 +20%）、`xue_yong` 血勇（自身残血 +12%） |
| 适用敌情 | 多小怪、需要快速减员；敌人带降防（赤炉刀卫）时裂甲额外生效 |
| 风险 | 气血越低越强，但与"减伤/治疗"路线互斥；遇到高防单体（铜角镇兽）收益下降 |
| 替代 | 若前 5 层没拿到收割条，转基础层 + 护盾路线 |

### 3.2 护盾续航（奇谋 3 条 + 坚守 1 条）

| 环节 | 内容 |
|---|---|
| 参与弟子 | 诸葛亮（八阵图给盾）、嫦娥、白素贞（防御向，护盾系数高） |
| 核心道法 | `qi_mou` 奇谋（护盾量 +18%）、`miao_suan` 妙算（**有盾时伤害 +12%**） |
| 配合道法 | `bu_dong` 不动（有盾时减伤 10%）、`shen_suan` 神算（速度 + 护盾量） |
| 适用敌情 | 群攻（问道真灵、引魂灯使）、需要站桩多轮 |
| 风险 | 盾被打破后增伤消失；对破盾快的敌人效率低 |
| 替代 | 没有护盾技能时，改用坚守的常驻减伤 |

### 3.3 恢复持久（坚守 5 条）

| 环节 | 内容 |
|---|---|
| 参与弟子 | 华佗（青囊）、嫦娥、杜甫、带治疗被动的辅助 |
| 核心道法 | `hui_chun` 回春（治疗量 +20%）、`pan_shi` 磐石（常驻减伤 −6%） |
| 配合道法 | `gui_xi` 龟息（残血减伤 −12%）、`yi_xin` 一心（减伤 + 治疗）、`jin_gang` 金刚（气血上限） |
| 适用敌情 | 长线消耗、20 轮上限局、敌人有持续伤害 |
| 风险 | 前 10 层伤害不足，可能被群攻磨死；对高爆发首领容错低 |
| 替代 | 前段先拿锋锐基础层过渡，后段转持久 |

**为什么这三条成立**：`target_wounded` / `low_hp` 是"越危险越强"，`shielded` 是"先投入后收益"，`taken_damage` 是"降低方差"。三者对气血、敌情、技能配置的敏感方向不同，不存在一条在所有状态下严格最优。

**实测修正**：原设计称"护盾进攻"，验证后改为"护盾续航"。增伤在当前战斗结构下无法稳定转化为击杀回合（见 `balance-report.md` 3.1），妙算的 +20% 伤害只作为盾体系内的辅助项，核心价值是盾量与减伤。不通过继续拉高数值掩盖该问题。

### 4.1 叠加与重复

- 同一 id 全局只能获得一次；抽到已拥有则从池中排除，不重复计入。
- 不同 id 的同键修正按加法叠加，受 2.3 上限约束。
- 属性类与修正类互不影响，按乘法作用于不同阶段。
- 条件修正不叠加同类倍数，只加百分点；同一条件多个来源直接相加。

### 4.2 与技能、被动、羁绊、专武的关系

| 来源 | 作用位置 | 是否被词条影响 |
|---|---|---|
| 主动技能系数 | `BattleAction.coefficient` | 是（damage 修正乘在系数后） |
| 被动常驻加成 | `BattleUnit.bonuses` | 是（同键相加） |
| 被动条件加成 | `passive.bonuses` + condition | 是（与词条条件同时满足则相加） |
| 羁绊修正 | 系数 / 目标数 / 时长 | 是（羁绊先改系数，词条再乘修正） |
| 专武 | `battle_bonuses` → `bonuses` | 是（同键相加，受上限） |

## 5. 候选与成长规则

### 5.1 抽取（明确改动，不默改）

| 项 | 现状 | 本期改为 |
|---|---|---|
| 组选择 | 按已选组数量加权（每条 +50%） | 保留 |
| 组内抽取 | 全组等概率抽 3，**不排除已选** | **排除已拥有**，抽 3 |
| 重复候选 | 可能重复出现 | 不会 |
| 组内不足 3 条 | 有几条给几条 | 从其他组补齐到 3（跨组） |
| 全池耗尽 | 可能返回空 | 给"道法精要"通用项（+2% 全属性，最多 3 次） |

### 5.2 核心获得时机

- 第 1–3 层：必出与当前队伍标签匹配的组（攻击型队伍优先锋锐，防御/辅助优先坚守或奇谋）。
- 第 4 层起：按 5.1 的权重自由抽取。
- 第 10 层（首个耐久检查点）、第 15 层：额外给一次三选一（不改变总层数，只是在既有奖励上加一次选择）。

> 这一条属于玩法节奏，若与 T22 冲突以 T22 为准；本期可先只做 5.1，不动 5.2。

### 5.3 上限与兜底

- 单键修正按 2.3 截断。
- 一局最多 19 次选择，池共 20 条，不会耗尽。
- 组内不足 3 条时跨组补齐；若整个池已空（理论不可达），跳过本次选择直接生成下一层候选，不引入虚拟词条。

## 6. 三个选择案例

### 案例 A：满血 vs 残血

- 状态：第 8 层，队伍平均气血 82%，候选为 `shi_ru_po_zhu`（残血目标 +15%）与 `pan_shi`（常驻减伤 −6%）。
- 满血时：残血增伤短期不生效，选磐石更稳。
- 残血时（<50%）：收割能立刻结束战斗，选势如破竹。
- **结论**：同一候选的价值随当前气血反向变化。

### 案例 B：高防单体 vs 群攻

- 状态：第 12 层，候选 `lie_jia`（降防目标 +12%）与 `qi_mou`（护盾 +18%）。
- 面对铜角镇兽（高防单体）：降防来源少，裂甲收益低；护盾能扛住冲阵，选奇谋。
- 面对引魂灯使（群攻降攻）：裂甲配合降防收益高，且需要快速减员，选裂甲。
- **结论**：价值取决于敌情与是否已有降防来源。

### 案例 C：已有 3 条锋锐 vs 已有 2 条坚守

- 状态：第 14 层，候选同时出现锋锐与坚守（跨组补齐时）。
- 已 3 条锋锐：边际收益递减且受 damage 上限约束，转坚守补生存更优。
- 已 2 条坚守：护盾/减伤尚未成形，继续堆输出可能被首领拖死。
- **结论**：组权重会推动"专精"，但上限与敌情会拉回"补短板"。

## 7. 一条构筑的形成过程

**目标：护盾进攻**

| 层 | 选择 | 理由 |
|---|---|---|
| 1–3 | `qi_mou` 奇谋（护盾 +18%） | 队伍有诸葛亮，八阵图给盾，先把盾量拉起来 |
| 4–6 | `miao_suan` 妙算（有盾增伤） | 核心转化：把护盾变成输出 |
| 7–9 | `bu_dong` 不动（有盾减伤） | 提高盾的存活时间，间接提高增伤覆盖率 |
| 10–12 | `shen_suan` 神算（速度 + 护盾量） | 先手给盾，避免开局被打穿 |
| 13–15 | `tie_bi` 铁壁（防御） | 补基础生存，避免盾破后崩盘 |
| 16–19 | `tong_chou` 统筹 / `yi_xin` 一心 | 全属性与减伤收尾 |
| 20 | 首领 | 靠"盾在则增伤"打满 20 轮 |

**核心未出现时的替代**：
- 没拿到 `miao_suan`：转"恢复持久"，用 `hui_chun` + `pan_shi` + `gui_xi`，靠治疗与减伤磨。
- 没拿到 `qi_mou`：转"破甲收割"，用 `shi_ru_po_zhu` + `yi_gu_zuo_qi` + `xue_yong`，靠首轮与残血爆发。
- 两者都没拿到：基础层（`tie_bi`/`jin_gang`/`ji_feng`/`tong_chou`）保证不崩，等下一次三选一。
