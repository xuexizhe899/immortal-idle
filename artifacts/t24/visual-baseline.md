## 1. 本轮依据与边界

本基准承接 `ART_DIRECTION.md` 的 `0.3.0` 细像素修仙风：青灰与玉绿、象牙白石、暖木、克制金色，左上暖光，清楚的轮廓。正式人物与场景保持既有资产，不重绘、不生图。

已核对 `style.css`、`PanelModal.vue`、`NoticeBubble.vue`、宗门总览、炼制页面与资源解析。宗门的资源、值守、挂机收益已有实现；疗伤丹清除所选弟子的全部伤势；青龙偃月刀的加成、消耗与解锁条件来自当前配置。复盘和远行在同轮代码中继续完成，本样板不以未完成的流程为必要前提。

样板位于 [`preview.html`](preview.html)。直接在浏览器打开即可使用本地资源，未连接 API、存档或外部服务。示例持有量和进度只用于排版，不是测试战果；全部演示状态留在 `artifacts/t24/`，正式界面没有新增预览入口。

## 3. 可执行规则

### 色彩与材质

| 用途 | 当前值 / 形状规则 | 例子与反例 |
|---|---|---|
| 页面基底、纸面 | `--bg #e9e3d2`、`--surface #f8f2df`、`--surface-raised #fffaf0` | 正文用实色纸面，标题区稍亮；不在密集正文后叠纹理或场景噪点。 |
| 正文与辅助文字 | `--text #293a33`、`--ink #243b35`、`--muted #5e6d60` | 消耗与限制能直接阅读；不能用更浅的颜色隐藏不可用原因。 |
| 主操作、已确认状态 | `--jade #2d6c57` | “给关羽服用”用一处青绿主按钮；同一决策区不要铺满多个同等强调按钮。 |
| 金色 | `--gold #b48743` | 用于眉题、器物身份等少量点缀；关键结果不只靠金色或稀有度边框表达。 |
| 错误 / 危险操作 | `--danger #a44e3f`，配明确文案 | 气泡使用“戒”与错误内容；不能只把边框染红而不说明发生了什么。 |
| 木、玉与金属 | 资产中的结构、硬边与分段高光承担材质 | 木柄保留细长轴线，玉瓶保留瓶口/瓶肩，刀刃有厚度和刃面；不能用同一轮廓换色冒充不同器物。 |

### 文字、数字与留白

- 标题沿用本地 `STSong / SimSun`，正文沿用 `Microsoft YaHei / PingFang SC`；不新增远程字体或强制全站像素字。
- 弹窗标题桌面 25px、手机 22px；正文以 14px 为基准，手机全局 13px；说明以 12px 为基准。10px 眉题仅承担装饰性身份，不承载消耗、限制或错误。
- 资源数字沿用等宽数字排版；单位与“持有 / 需要”同组，长数量不得挤掉操作。不能把“缺少 1 个玄晶”藏在仅悬停可见的提示里。
- 页面先给身份与当前状态，再给结果、消耗和行动。用段间留白、细分隔线建立层次，不把每句文案都框成卡片。
- 公共容器桌面正文间距 24–26px，手机 14–18px；业务页面仍保留自身布局，不把页面样式全部搬进全局文件。

### 操作与反馈

| 状态 | 表现和位置 | 不采用的做法 |
|---|---|---|
| 正常 | 主按钮写具体动作，旁边列消耗与对象 | 只有“确定”而不说明服用对象或结果。 |
| 选中 | 沿用已有标签/按钮的实色底，保留文字 | 只用细微颜色差异表示选中。 |
| 等待 | 禁止重复提交，动作改为正在执行；气泡使用“候” | 假百分比、预计剩余时间、未确认就显示成功。 |
| 不可用 | 按钮可读且不响应，具体原因紧邻按钮 | 仅降低透明度、隐藏按钮或让玩家点击后才知道缺材料。 |
| 错误 | 错误气泡保留；说明现状与可采取的下一步 | 自动重发消耗命令，或把错误改成绿色成功提示。 |
| 普通反馈 / 成功 | 普通消息用“讯”；只有服务端确认后才写“完成”“已入库” | 所有通知都统一写“操作成功”。 |
| 焦点 | 全局 2px 青绿轮廓，关闭按钮聚焦时清楚可见 | 用 `outline: none` 抹掉按钮键盘焦点。 |
| 缺图 | 保留名称、用途、尺寸和文字占位 | emoji、随机占位图或错误器物图代替。 |

聊天气泡仍保留现有 `status / alert`、`aria-live`、普通提示计时、悬停与聚焦暂停；等待不可关闭，错误不自动消失。弹窗保留 Escape、Tab 循环、关闭后焦点恢复及背景滚动锁定。本轮只修改这些组件的样式，不改变脚本逻辑。

动效沿用短过渡与既有气泡进入，`prefers-reduced-motion` 保持禁用/缩短动画。新页面不把装饰做成持续闪动的主焦点。

## 4. 两种代表样板

`preview.html` 包含两种样板，均随视口宽度响应；宽屏查看桌面布局，视口设为 390px 查看手机布局。没有把 HTML 排版当成渲染已验收。

1. **普通功能面板：宗门总览。** 身份 → 四项资源 → 收取挂机收益 → 宗门现况。正常、等待、出征期间不可用与长错误消息均有独立位置。
2. **高密度详情：疗伤丹与青龙偃月刀。** 身份/对象 → 24px、32px 小图及 128px 独立详情稿 → 当前、消耗、结果、限制 → 主操作。两件器物各有等待、不可用和错误示例，手机按纵向排列。

样板没有模拟弹窗焦点陷阱、滚动锁定和气泡计时；这些行为在正式组件人工检查。预览中的普通按钮只展示样式，不触发真实命令。
