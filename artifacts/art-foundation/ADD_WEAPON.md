# 专属武器美术 · 可复用提示词

适用于新增或精修专武外观。当前 T19 使用“生图参考 → 本地代码绘制 SVG”的流程：参考图保存在 `assets/masters/weapons/`，正式图标为 `frontend/public/assets/items/<weapon_id>.svg`。参考图存在不等于已作为游戏展示图接入，外观制作也不自动授权修改武器属性或获取规则。

## 交给执行者的任务指令

```text
为当前修仙游戏制作专属武器美术。

所属弟子：【姓名 / template_id】
专武名称与 ID：【名称 / snake_case ID】
本次操作：【新增美术储备 / 精修指定现有专武】
外观锚点：【武器类别、主体轮廓、材质、主色、标志性结构或纹样】
与现有同类的区别：【例如刃形、护手、弓臂或器物结构，不能只换色】
生图授权：【无需生图，复用现有参考 / gpt-image-2.6-sunburst，最多 N 次调用】

先读 AGENTS.md、ARCHITECTURE.md、ART_DIRECTION.md、
artifacts/t19/item-rules.md 和 artifacts/art-foundation/ADD_WEAPON.md。
核对 config/weapons、所属弟子立绘、assets/masters/weapons、
assets/prompts/weapons 与 assets/manifest.json。
现有16把专武已有参考图，先复用，不因开启新任务重新生成整批。

延续0.3.0细像素修仙风：硬边像素簇，青绿、象牙白、暖木、
深铁与克制金色，左上暖光。造型体现弟子身份，不能所有武器都加龙纹。
保留真实器物类别：药箱、扇、琴、仪、书卷等不能统一改成长剑。
完整单件主体、清楚轮廓、合理连接结构与材质层次，纹样不能淹没结构。

仅确需新参考时使用已授权模型；先核实实际调用路径支持指定模型。
无法选择模型时说明限制，不声称已使用指定模型，也不默换模型。
失败、尺寸降级和重试均计入上限；检查现有结果与恢复记录后再决定，
不盲目重试，不沿用其他任务的剩余额度。
批量先按现有规则做代表试稿，经确认后连续制作授权名单。

参考图用于造型与材质研究，纯深青灰底即可，不冒充透明运行图。
建议方形1024×1024，单件居中，长兵器可斜置但必须完整留边；
不得出现人物、手、场景、文字、卡框、底座、UI、水印或第二件物品。
保存原始参考与脱敏完整提示、真实模型信息、尺寸和调用次数。

正式图标使用本地SVG代码绘制，viewBox为0 0 64 64，透明背景，
shape-rendering=crispEdges，保留可复现绘图源码与命令。
在24/32/40/64px下仍能辨认轮廓和身份。
不把位图嵌入SVG，不用自动描摹位图冒充本地手绘，不用emoji。

已有正式专武：在tools/generate_item_icons.py添加或精修对应ART绘图，
定向生成，保留其他图标与index.json条目。
新增正式ID时核对配置、生成清单、assetPaths.ts的ITEM_ICON_IDS及引用；
只做储备且没有正式配置时，使用任务自己的草稿输出，不强行写玩法配置。
沿用ItemIcon与现有装备/锻造界面的本地资源路径，不另写生图运行时接口。

本次只做美术，不修改属性、技能、材料、解锁条件、归属、存档或战斗结果。
若需要完整接入一把新专武，先提出独立配置方案；图片不等于玩法已完成。
默认不增加详情大图；若用户明确需要，另定展示规格、路径与接入范围，
不能把64px小图放大后当成精修插画交付。

交付：参考复用/生成情况、SVG与源码、定向命令、资源登记、
浅深底和24/32/40/64px对照，以及实际调用数和检查结果。
视觉由用户人工确认；保护其他未提交修改，验证遵从本次明确指令与AGENTS。
```

## 直接用于生图的主体模板

以下生成的是**单件专武参考图**。所属弟子用于约束器物身份，画面中不出现人物。将方括号替换为实际内容；生图前仍需本任务模型与预算授权。

```text
用途：为细像素修仙游戏制作一张单件专属器物设定参考，
后续将据此用代码手绘64×64透明SVG图标。

主体：【弟子姓名】的【专武名称】，类别为【刀/枪/弓/扇/琴/药箱等】。
轮廓：【描述最能辨识的主体形状、比例和朝向】。
结构：【刃/弓臂/羽片/箱体等主体、连接部件、柄/支架的明确关系】。
材质：【最多三种主要材质】，主色【颜色】，点缀【颜色】。
身份锚点：【一至两个与该弟子直接相关的纹样或结构】，
让身份通过器物造型表达，不画弟子本人，不堆砌无关装饰。

风格：沿用项目0.3.0细像素仙侠美术，清晰硬边、有意组织的像素簇，
有限色板，材质通过形状、明暗色块与像素纹理区分。
青绿、象牙白、暖木、深铁与克制金色相协调，左上暖光、冷色暗部。
结构应清楚到可转绘为小图标，细节服从轮廓，不能靠发光掩盖形状。

构图：方形画布，单件完整居中，四周约一成留白；
【长兵器斜置 / 扁平器物正面略侧 / 立体器物三分之四视角，按器形选一】。
纯深青灰平底，主体边界清楚，所有尖端、柄尾、弦与装饰均在画内。
不画场景、支架、展示台、人物、手、持有者、第二件物品或多视图拼版。

禁止：照片质感、平滑插画、塑料3D、柔焦、霓虹、粒子光效、
夸张光晕、文字、签名、水印、边框、卡片、UI、模糊轮廓、裁切主体。
```

青龙偃月刀的主体段可写：

> 关羽的青龙偃月刀，一把完整长柄偃月刀。宽阔弧形银灰刀刃位于杆首，刀背厚重，刃口清楚；青玉龙首形刀颈衔接深色暖木长柄，少量暗金箍环与短红缨。克制龙鳞纹沿刀颈分布，不把整条龙盘满刀身。以偃月刃、长柄和龙首刀颈形成独特轮廓；不画关羽、手、坐骑或背景。

## 当前流程的接入注意

- `assets/prompts/weapons/trial-01.json`、`batch-02.json` 是含历史结果信息的生成记录。其 `file` 为仓库路径，不能原样当作 `tools/gen_assets.py --preset` 的可执行预设；该工具的 `file` 必须位于所选 raw 输出目录内。
- `gen_assets.py` 当前没有专武类型的公共提示分支。不要照搬人物 `kind: portrait`，否则会混入人物/全身站姿语义；也不要照搬建筑分支。确需扩展项目管线时，应先说明最小工具变更，保留独立器物主体、公共风格和反向约束，不静默绕过既有风格规则。
- 原图扩展名与尺寸按真实返回格式登记，不通过改扩展名伪装无损文件；现有 `.jpg` 参考不能描述为透明PNG。
- 现有专武美术登记应沿用正式 ID，例如青龙偃月刀为 `qinglong_yanyuedao`；`guanyu_signature` 是早期审阅概念，不作为正式专武 ID。
- 同一弟子当前只对应一把正式专武。新增第二把、改变获取/装备规则或改用位图运行资产，均需明确新的任务范围。
- 精修已有正式图标时，可从仓库根目录定向生成：

```powershell
backend\.venv\Scripts\python.exe tools/generate_item_icons.py --only qinglong_yanyuedao
```

该命令只绘制本地SVG，不调用模型；`--only` 只接受已有正式物品配置中的 ID。新美术储备不能先塞入正式配置以绕过此限制。

本文只提供提示词与流程，本次编写未生成参考图、未修改武器或图标、未调用付费API。
