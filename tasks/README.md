## T21 之后的推进顺序

按 `T20 → T21 → T22 → T23 → T24（前端美术）` 推进。T21–T23 先深化现有问道塔：词条影响打法，路线形成可判断的取舍，失败与成长能指导下一局。各卡先核对前期实际结果，保存相同投入的对照；计划与候选规则不能写成已实现。

T24 从用户确认的前端美术优化方向开始，先建立视觉基准、两种代表样板和有限公共样式；任务见 [T24](T24-visual-baseline.md)。后续再拆主城与导航、弟子/培养/装备、丹药专武、问道塔及动效反馈，最后收口移动端与性能；T25–T30 尚未生成任务卡。沿用细像素修仙风、青绿/象牙白/暖木/克制金色，以实际样板明确层级、材质、图标和桌面/390px 规则，不一次性铺开全站重绘。

T21–T23 只增加支撑玩法判断的必要展示，统一的视觉改版归入 T24。现有角色、场景与本地美术资产优先复用，生图按届时任务明确模型与预算，历史额度不自动延续。远征、入侵、更多养成轴不作为这几期的默认扩展内容。
