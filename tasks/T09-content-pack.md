# T09 · 词条、丹方器方与爬塔内容包

- 里程碑：M3 ｜ 依赖：T01、T06 ｜ 对应文档：DESIGN.md 第 7.6、7.7 节

## 目标
铺首版可玩内容：词条池、炼丹炼器配方、爬塔 20 层与 1 个 boss，并验证数值曲线没有断崖。

## 已锁定决策
1. 词条首版 20 条 / 3 个协同组（完整版 40–60 条 / 6–8 组）
2. 丹方、器方首版各 6 条（完整版各 12–20），材料 20–30 种，单步合成为主
3. 炼丹管疗伤与增益，炼器管装备；炼丹是伤势闭环的主动解法
4. 爬塔完整版 100 层分 5 段，首版 20 层 + 1 个 boss
5. 远征、入侵者首版仅占位配置，不铺内容

## 要做的事
1. `config/affixes/`：20 条词条、3 个协同组、权重表（供 T05 加权抽取）
2. `config/recipes/`：丹方与器方各 6 条，含疗伤丹；材料表与产出绑定
3. `config/modes/tower.json`：20 层节点、敌人表、事件表、奖励表、boss 配置
4. 数值曲线初版：成长、敌人强度、奖励随层数的变化；用脚本离线模拟多层结果
5. `expedition.json`、`invasion.json` 写占位结构，保证引擎可加载但不开放入口

## 产出物
- 词条/配方/材料/爬塔配置、数值模拟脚本、曲线记录

## 验收
- [x] 全部配置通过 T01 校验（skills=32 / disciples=16 / bonds=5 / affixes=20 / materials=6 / recipes=12 / modes=3）
- [x] 词条按协同组加权：先选组、再组内抽三，已选组 +50%，单局能凑成套
- [x] 疗伤丹可炼制并清除伤势（冒烟：2 层伤 → 0，扣 1 灵草 + 1 云母）
- [x] 20 层可通关：5 人队 100 seed 全部通关，曲线见执行记录
- [x] 占位模式（expedition / invasion）`enabled=false`，爬塔不受影响

## 不做
远征/入侵内容、100 层全量、跨档排行、数值精调到商业化水平。

## 注意
首版最容易死在内容量上。若进度吃紧，优先保爬塔曲线与疗伤闭环，词条与配方数量可以再砍，但**不要砍验收**。
